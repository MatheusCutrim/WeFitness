# WeFitness CT

Site de apresentação e contato da WeFitness, Centro de Saúde, Performance e Longevidade em Manaíra, João Pessoa. A página foi pensada para quem chega pelo link da bio do Instagram e quer conhecer o CT, conversar com a equipe ou abrir uma rota até a academia.

[Acessar o site](https://wefitnessct.magnificentpelican4.chatgpt.site/)

## Estrutura

A aplicação é estática e usa HTML, CSS e JavaScript. A pasta `dist` contém a página, os estilos, a lógica de abertura dos aplicativos de mapas e os arquivos de imagem e fonte.

## Executar localmente

Com Python instalado, rode na raiz do repositório:

```sh
python -m http.server 8000 --directory dist
```

Abra http://localhost:8000 para visualizar a página.
